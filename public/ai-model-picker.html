How the call gets made

Three passes, in this order — because a constraint you cannot break should eliminate a model before any score gets compared.

PASS 01

Filter

Hard constraints cut the pool first. "Must stay in-house" removes every hosted API, whatever it scores. "Real time" removes anything that thinks before it answers. Whatever gets cut is listed, with the reason.

PASS 02

Weight

The task type sets a base weight on each of the nine axes; keywords in your description bend them. Say "cheap" and Value doubles. Say "400-page" and Context does. The weights in play are printed under the readout.

PASS 03

Score

Every surviving model is a weighted sum of its axis scores, normalised to a 0–100 match. Anything inside four points of the winner is a coin flip — pick on price, or on whichever API you already have a key for.
