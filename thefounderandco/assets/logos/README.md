# Client logos

The wall in section 06 of `company.html` reads from this folder. Until a
file is here, that company shows as a wordmark instead — so the wall is
never broken and you can fill it in one logo at a time.

## Naming

Name the file exactly as listed, `.svg` preferred, `.png` accepted:

    sanabil-venture-studio      nana
    raed-vc                     mrsool
    impact46                    d360-bank
    stryber                     floward
    mozn                        resal
    foodics                     walaplus
    jahez                       syarah

SVG is tried first, then PNG, then the wordmark. To add or remove a
company, edit `LOGOS_A` / `LOGOS_B` in `company.html`.

## What the files should be

- **Horizontal lockup**, not the square app icon — the pill is wider than
  it is tall.
- **Dark or full-colour artwork on a transparent background.** The wall
  renders logos flat grey at rest and gives the real colour back on hover,
  so a white-only logo would disappear against the white pill. If a
  company only publishes a white version, ask for the dark one.
- **Trim the whitespace** in the file. Padding baked into the artwork makes
  that logo look smaller than its neighbours.
- PNG at 3x the display size — roughly 450px wide, 84px tall — so it stays
  sharp on retina screens. SVG needs no particular size.

Most companies publish these in a press or brand kit page. Where they
don't, asking the marketing contact usually gets a proper file back within
a day, and it is worth the wait over a screenshot.

## One thing worth checking

Naming clients you have worked with is normal practice, but some client
agreements restrict use of the logo or the relationship in marketing. If
any of these were engaged under an agreement with a publicity clause,
worth a look before the wall goes live.
